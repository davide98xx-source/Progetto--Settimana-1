Pagina ricetta

Tecnologie: HTML5, CSS3, Git.

Una pagina web che presenta una ricetta di cucina. Esercizio di markup semantico applicato a un contenuto reale: titolo principale, sezioni distinte per ingredienti e procedura, lista ordinata per i passaggi, immagine del piatto finale con didascalia.

Cosa ho imparato: scegliere il tag giusto in base al significato del contenuto e non all'aspetto visivo. Differenza tra per le immagini con didascalia.

Tessera di presentazione

Tecnologie: HTML5, CSS3, Font Awesome.

Un biglietto digitale con nome, ruolo, foto profilo e link ai social. Esercizio su tag semantici, link esterni con Prima esperienza con le icone di Font Awesome.

Cosa ho imparato: organizzare l'informazione in poco spazio mantenendo gerarchia visiva.

Portfolio personale

Tecnologie: HTML5, CSS3, Google Fonts, Font Awesome, Git, GitHub Pages.

La pagina che state vedendo. Costruita da zero in cinque giorni, partendo dal markup HTML e arrivando alla stilizzazione CSS completa con box model, pseudo-classi, pseudo-elementi e tipografia ragionata. Pubblicata online su GitHub Pages al termine della prima settimana di corso.

Cosa ho imparato: progettare una pagina pensando alla gerarchia dei contenuti prima del design. Stilizzare in modo consapevole partendo da un reset CSS. Gestire un repositoryGit con commit descrittivi. Pubblicare un sito statico online.
